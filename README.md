# Panduranga Yarlagadda — Portfolio

A responsive personal portfolio site built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. The site has no build step or package dependencies.

## Host with GitHub Pages

1. Push this repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.

GitHub Pages will show the published site URL in that settings panel after the first deployment completes.
